# 🎟️ Infernofest

Bienvenido a la documentación del proyecto web de **Infernofest**, un evento cultural y musical pensado para ofrecer una experiencia completa a los visitantes. La página está diseñada como un sitio estático con varias secciones informativas, de registro y contacto.

## 🌐 Descripción del proyecto

Infernofest es una landing page para promocionar un festival con:

- fechas del evento
- itinerario y programación
- patrocinadores
- información de contacto
- formulario de registro
- preguntas frecuentes
- políticas legales y de privacidad

La web está desarrollada con HTML y CSS, y está pensada para mostrarse en navegadores modernos sin necesidad de frameworks ni dependencias.

## ✨ Características principales

- Diseño visual atractivo y moderno
- Navegación clara entre secciones
- Páginas dedicadas para FAQ, contacto y registro
- Sección de patrocinadores con enlaces externos
- Layout responsivo para distintos tamaños de pantalla
- Información legal y de cookies

## 📁 Estructura del proyecto

```text
WEB_PROJECTE1/
├── index.html             # Página principal

├── contacte.html          # Información de contacto

├── cookies.html           # Política de cookies

```

## ▶️ Cómo ejecutar el proyecto

### Opción 1: abrir directamente en el navegador

1. Abre la carpeta del proyecto.
2. Haz doble clic sobre `index.html`.
3. La página se mostrará en tu navegador.

### Opción 2: usar un servidor local

Si prefieres visualizarlo desde un servidor local:

```bash
python -m http.server 8000
```

Luego abre esta URL en tu navegador:

```text
http://localhost:8000
```
